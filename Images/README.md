# Ảnh sản phẩm

Toàn bộ ảnh PNG đặt trực tiếp trong thư mục này, không chia thư mục theo nguồn tải.

Quy tắc: chữ thường, không dấu, các từ ngăn bằng dấu gạch ngang (`kebab-case`).

Ví dụ:
- `americano-classic.png`
- `cappuccino-nong.png`
- `tra-dao-cam-sa-da.png`
- `tran-chau-trang.png`
- `matcha-layers-dau.png`

Tên món hiển thị trong POS vẫn giữ tiếng Việt có dấu. Ánh xạ ảnh nằm ở `TheCafePOS_WPF/TheCafePOS_WPF/Assets/Menu/thecoffeehouse.json`; bảng chuyển đường dẫn cũ nằm ở `image-renames.json` cùng thư mục. Ứng dụng tự cập nhật đường dẫn ảnh đã lưu khi khởi động, không thay đổi giá hoặc cấu hình món.

Có 83 ảnh: 81 đã gắn menu và 2 ảnh Matcha Layers Dâu/Xoài đang chờ xác minh món/giá. Thay ảnh giữ nguyên tên file rồi build lại để đóng gói phiên bản mới.
